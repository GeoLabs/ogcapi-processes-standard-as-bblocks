
# Media Types (Clause)

`ogc.api.processes.part1.clauses.mediaTypes` *v2.0*

Media types and profile identifiers of OGC API — Processes — Part 1: Core (DRAFT, OGC 18-062r3).

[*Status*](http://www.opengis.net/def/status): Under development

## Description

JSON media types that would typically be used in a server that supports JSON are:

- `application/json` for all resources.

The typical HTML media type for all “web pages” in a server would be:

- `text/html`.

The media type for an OpenAPI 3.0 definition is `application/vnd.oai.openapi+json;version=3.0` (JSON) or `application/vnd.oai.openapi;version=3.0` (YAML).

**NOTE:** The OpenAPI media types have not yet been registered with IANA and may change in the future.

As previously mentioned in the [“Content negotiations by profile”](#sec-7.7) clause, in some circumstances the use of generic media types, such as `application/json`, is too ambiguous. To more specifically identify responses generated by a server compliant with this Standard, the following profile URIs are defined:
